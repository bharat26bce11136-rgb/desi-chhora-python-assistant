# Desi Chhora – Python AI Assistant

## Overview
Desi Chhora is a menu-driven command-line assistant developed in Python. It combines several small utilities and interactive features in one console application.

## Features
- Basic conversational responses
- Calculator for addition, subtraction, multiplication and division
- Prime number checking
- Maximum and minimum number detection
- Three-question quiz with score
- Current date and time display
- Help menu
- Exit option
- Basic input validation for calculator input and division by zero

## Technologies / Tools Used
- Python 3
- `datetime` module
- Command-line interface / terminal

## Project Workflow
1. Start the Python program.
2. The main menu is displayed.
3. Select an option from 1 to 8.
4. Enter the required input.
5. The selected feature processes the input and displays the result.
6. The menu continues until option 8 is selected.

## How to Run
1. Install Python 3.
2. Save the source code as `main.py`.
3. Open a terminal in the project directory.
4. Run:
   `python main.py`
