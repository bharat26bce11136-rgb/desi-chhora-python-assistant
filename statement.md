# Project Statement

## Project Title
Desi Chhora – Python AI Assistant

## Problem Statement
The project aims to develop a simple command-line based assistant in Python that provides multiple useful interactive features through a single menu-driven application. The assistant can handle basic conversation, perform calculations, check prime numbers, find maximum and minimum values, conduct a quiz, display the current date and time, and provide help.

## Scope of the Project
The project is a Python-based console application designed for learning and demonstrating fundamental programming concepts such as input/output, conditional statements, loops, arithmetic operations, lists, exception handling, functions from the datetime module, and interactive menu-driven workflow.

## Target Users
- Students learning Python programming
- Beginners practicing basic programming concepts
- Users who want to interact with a simple command-line assistant

## High-Level Features
1. Baat-Cheet / basic conversation
2. Calculator
3. Prime Number Check
4. Maximum / Minimum
5. Quiz
6. Date & Time
7. Help menu
8. Exit option
